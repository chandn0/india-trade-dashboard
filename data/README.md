# Data Directory

This directory holds committed data snapshots and reviewed analytical inputs
used by the production dashboard. Generated JSON/CSV outputs should not be
hand-edited; regenerate them with the matching script. Explicitly identified
classification and enrichment CSVs are curated inputs and may be reviewed
directly. See `npm run refresh:all` and the inventories below.

## Key field definitions

### `data_status`

| Value | Meaning |
|-------|---------|
| `"annual"` | Completed fiscal year; data confirmed from official March cumulative row. |
| `"provisional"` | Latest fiscal year in progress; March row not yet published. Figures may be revised. |

### Fiscal year convention

A fiscal year runs April → March. It is identified by its start year: FY2024-25
has `financial_year = "2024-25"`. All scripts and JSON files use this format.

### Values

All monetary values are **US $ Million** unless otherwise noted.
Exchange rates are **INR per 1 USD** (annual average unless noted).

## FTSPCC vs FTPA vs HS-4 totals: known reconciliation gap

The dashboard uses three official sources that report slightly different annual
trade totals for the same fiscal year:

| Source | Used for | Known divergence |
|--------|----------|-----------------|
| **FTSPCC** (country-wise page) | Headline export/import totals, trade balance, yearly trend | Authoritative for aggregate; this is the series in `india_trade_yearly_raw.json`. |
| **FTPA** (commodity-group reports) | Commodity basket shares | Shares are normalized to 100 % within FTPA's own totals; the FTPA absolute total can differ from FTSPCC by up to a few percent in recent years due to provisional vs. revised data timing. |
| **TIA / HS-4** (item-level extraction) | HS-4 product movers | HS-4 totals aggregate to a different figure than FTSPCC in some years; the TIA endpoint uses a "World" aggregate that may exclude a small number of partner categories. |

**Rule of thumb:** use FTSPCC figures for any absolute trade-value claim. Use
FTPA/TIA only for shares and composition. Never directly compare absolute
figures from different sources without noting the caveat. See
[`docs/india-trade-trends.md`](../docs/india-trade-trends.md) §"Data and
methodology notes" for the full caveat.

# Product discovery

`import_product_classification.csv` is the hand-curated, auditable classification
layer for the Buildability Atlas. `product_discovery.json` is generated by
`npm run build:product-discovery`, which joins those judgments to the committed
HS-4 trade and dependence snapshots in `derived/`.

The classification includes a low/high realistic-reduction scenario. It is
applied to the product's **net deficit**, never its gross import value. These
ranges are directional research assumptions and should be revised as stronger
sector evidence becomes available.

`product_stage_classification.csv` contains reviewed HS-4 overrides with an
explicit dominant production stage and attribution rationale.
`product_stage_mix.json` is generated with `npm run build:product-stage-mix` and
covers every available HS-4 line. `product_stage_summary.json` omits the large
product index so the main dashboard preview does not download the dedicated
workspace's full dataset. Products without a reviewed override receive a
transparent, lower-confidence HS-2 dominant-use assignment. See
`docs/product-stage-methodology.md` for precedence, definitions, and caveats.
